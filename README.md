# devops-lab2-CALMS
Lab 2: Thiết lập môi trường DevOps &amp; Áp dụng Nguyên tắc CALMS

## BƯỚC 5: CALMS Self-Assessment (10 phút)

### 5.1 Tự Đánh giá DevOps Maturity

Chấm điểm team/ cá nhân bạn theo thang 1-5:

| Nguyên tắc | 1 (Yếu) | 3 (Trung bình) | 5 (Xuất sắc) | Điểm của bạn |
|-----------|---------|---------------|-------------|:---:|
| **C**ulture | Dev vs Ops đổ lỗi cho nhau | Dev với Ops ngồi chung team | Mọi người cùng chịu trách nhiệm production | 5/5 |
| **A**utomation | Deploy thủ công 100% | Có CI/CD cho 1 số project | Toàn bộ pipeline tự động | 5/5 |
| **L**ean | Setup môi trường mất > 1 ngày | Có script, Docker 1 phần | 1 lệnh → môi trường sẵn sàng | 5/5 |
| **M**easurement | Không biết app có đang chạy không | Có monitoring cơ bản | Dashboard real-time + alert | 5/5 |
| **S**haring | Mỗi người tự biết, không document | Có wiki nội bộ | Code review + post-mortem + knowledge sharing | 5/5 |
| **TỔNG** | | | | **25/25** |

### 5.2 Kế hoạch Cải thiện

1. Cần tập trung vào dự án hơn
2. Cần thông thạo sử dụng nhiều công cụ hơn
3. Cần thông thạo viết script hơn
